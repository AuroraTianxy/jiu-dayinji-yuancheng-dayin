# Third-party components

- `pdf-to-printer` 5.6.0, https://github.com/artiebits/pdf-to-printer — MIT License, Copyright (c) 2019 artiebits. Installed by npm using the version/integrity recorded in package-lock.json. Its own license remains in the installed dependency. This project calls its public API; no source from the wrapper is copied into our application files.
- `pdf-to-printer` uses the SumatraPDF engine. SumatraPDF: https://github.com/sumatrapdfreader/sumatrapdf ; official site https://www.sumatrapdfreader.org/free-pdf-reader . The engine and its embedded third-party components retain their own licenses; the wrapper's MIT license does not replace them. Download the executable dependency via npm. Preserve upstream notices when installing or redistributing dependencies.

Windows printer drivers must be obtained from the printer manufacturer's official distribution. No driver is bundled or downloaded by this program.
